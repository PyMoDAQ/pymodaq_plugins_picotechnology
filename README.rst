Instruments
===========

Viewer0D
++++++++

* **PicoLog TC08**: control of PicoLog TC-08 thermocouple data logger


Installation instructions
=========================

* PyMoDAQ’s 5.0.x or later
* Requires installation of Pico SDK:
        https://www.picotech.com/downloads/sdk-release/pico-software-development-kit-64bit
* Implemented for type K thermocouple only but this could easily be changed.
